How to read this dashboard

Price: Historical monthly closing-price illustration.

SMA 50: Average of the latest 50 monthly observations.

SMA 200: Average of the latest 200 monthly observations. Since this sample spans 60 months, the line appears only when enough observations exist; otherwise it is unavailable.

Trend: A simple comparison of the latest price with moving averages. It is not a trading recommendation.

Educational demo only. Values are generated sample data, not actual exchange prices or investment advice. Chart.js requires an internet connection to load.
